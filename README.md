## Contexte

Projet collectif réalisé en 2025 dans le cadre de ma formation en Technique d’intégration multimédia (Cégep Édouard-Montpetit). L’équipe devait produire un prototype plus ambitieux qu’un projet individuel, en mettant l’accent sur la coordination, la gestion de version et la répartition des responsabilités.

## Objectifs

- Réaliser un prototype de jeu vidéo complexe avec Unreal Engine, en équipe
- Définir les rôles et des conventions de travail collaboratif
- Intégrer régulièrement le travail de chacun sans conflits majeurs

1. Installer l’[Epic Games Launcher](https://www.unrealengine.com/download) et Unreal Engine **5.X** *(version à confirmer dans le fichier `.uproject`)*.
2. Installer [Git LFS](https://git-lfs.com/), puis cloner le dépôt :
   ```bash
   git lfs install
   git clone https://github.com/jaajness/jeu-unreal-equipe.git
   ```
3. Double-cliquer sur le fichier `NOM_DU_PROJET.uproject` (accepter de compiler les modules si demandé).

## Démarche

1. **Organisation de l’équipe** — rôles, responsabilités, outils de gestion de version et conventions
2. **Conception collaborative** — mécaniques, univers visuel et architecture technique, avec un document de conception partagé
3. **Développement parallèle** — systèmes développés simultanément, intégration régulière pour éviter les conflits
4. **Intégration & débogage** — fusion des modules, résolution des conflits techniques et ajustement des interfaces entre systèmes
5. **Polish & livraison** — tests croisés, corrections finales et présentation à la classe

## Résultats
